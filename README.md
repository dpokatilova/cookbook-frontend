# CookBook — Frontend
 
Фронтенд для платформи **CookBook**: сторінка зі списком рецептів, які завантажуються з Django REST API.
Можна відфільтрувати рецепти за категорією.
 
Бекенд: https://github.com/dpokatilova/cookbook
 
## Адреси та порти
 
| Частина | Адреса |
| --- | --- |
| Фронтенд | http://127.0.0.1:3000 |
| Бекенд (API) | http://127.0.0.1:8000 |
 
Адреса бекенду задана в `script.js` (константа `API_URL`).
Фронтенд запускається на іншому порту, тому на бекенді налаштований CORS: порт 3000 дозволений у `CORS_ALLOWED_ORIGINS`.
 
## Як запустити проєкт
 
1. Запустіть бекенд (інструкція в README бекенд-репозиторію), щоб API працював на `http://127.0.0.1:8000`.
2. Перейдіть у папку з фронтендом:
```bash
   cd cookbook-frontend
```
 
3. Запустіть простий вебсервер на порту 3000:
```bash
   python -m http.server 3000
```
 
4. Відкрийте в браузері http://127.0.0.1:3000
